Reader, welcome. This is the public edition of the daily cyber brief from Shadow Night Intelligence (SNI). Everything in it is explained in plain words. A few terms first, because they appear all through the brief. A vulnerability is a mistake in software that lets an attacker do something they should not be able to do, like a lock that opens with the wrong key. A CVE is the official catalogue number given to one vulnerability, so everyone is talking about the same mistake. A patch is the repair the maker releases. An exploit is the tool or trick that uses a vulnerability. A score out of 10, called a CVSS score, measures how serious a vulnerability is: 9 or above is critical.

Top 3, must know

1. NFS2ROOT: a 12 year old flaw can hand full control of a Linux server to a stranger, no password needed

Linux is the free operating system that runs most of the world's servers. Inside it sits a file sharing service called NFS, which lets one computer use files stored on another. Researchers at OpenSec and France's ANSSI agency found a mistake in that service, catalogue number CVE-2026-99362, scored 9.8 out of 10. It has been sitting there since 2014. In plain steps: the service keeps a small notebook page for each visitor's last answer. A visitor can ask for a notebook page of size zero, then trick the service into writing a full answer onto that empty page. The extra writing spills onto the computer's most sensitive memory, the part that runs the whole machine, and the attacker can steer what happens next. OpenSec filmed an unauthenticated visitor, someone with no account and no password, ending up with a root shell, meaning total control of the server, using nothing but the file sharing port, number 2049. Think of a hotel front desk that copies your request onto a sticky note with no space on it, so the ink runs onto the master key card underneath.

There are no reports of criminals using this yet, and the attackers' tool is not public. The repair exists: fixed kernel versions include 6.12.117, 6.18.61, 6.6.163, 6.1.193, 5.15.226, 5.10.275 and 7.3.2. Some Linux distributions had not yet shipped the fixed packages on 26 November, so check your own distribution's update. If you cannot patch today, only let trusted computers reach port 2049, or turn the NFS server off if you do not use it, and restart the machine after updating so the fixed system actually loads.

What this means for you: if you run a Linux server that shares files over a network, this is your first job today. A stranger needs no password, only network reach.

Source: BleepingComputer, NFS2ROOT report, 27 November 2026

2. SAP confirms a security incident; reports say stolen employee tokens were used to copy and change source code

SAP is one of the largest business software companies in the world; its programs run the finance, staff and supply records of huge companies. SAP has confirmed it found suspicious activity in its computer systems and took urgent steps to protect customers. That confirmation is the solid part. The detail comes from the German magazine Der Spiegel, citing people inside SAP, and is not confirmed by SAP: attackers allegedly stole employee access tokens, which are like digital pass keys, and used them to copy and alter SAP's source code, the human readable instructions its software is built from, on GitHub, the site where the code is stored. Reports also say SAP restricted GitHub access, paused its automatic build systems and replaced its code signing keys, the stamps that prove software really came from SAP. SAP says its investigation so far shows no evidence that customer business data was accessed. Why it matters: if altered code ever reached real software releases, every customer installing it could be affected at once. That is called a supply chain attack, poisoning the well instead of robbing each house. There is no public proof that happened here.

What this means for you: if your organisation uses SAP software, watch for SAP's own follow up notices and be ready to verify updates carefully. No customer action has been announced.

Sources: BleepingComputer, SAP confirms security incident, 27 November 2026 and Security Affairs, 27 November 2026

3. Deadlines land today and tomorrow on flaws attackers are already using

The United States cyber agency, CISA, keeps a list called the Known Exploited Vulnerabilities catalogue, the KEV for short: flaws with proof that criminals are already using them. Two dates matter right now. The Drupal flaw CVE-2026-132165 has a federal fixing deadline of today, 27 November 2026. Drupal is a popular free system for building websites. This flaw lets attackers reinstall a live site through its setup page and take it over. Its follow on flaw, CVE-2026-136716, covers sites the first repair left in an unfinished install state; fix it with Drupal 11.4.14, 11.3.23 or 10.6.23. Then, tomorrow, 28 November 2026, eight of the ten flaws CISA added on 25 November fall due: five in Mitel MiCollab (office meeting and calling software; the worst, CVE-2026-133323, scores a perfect 10.0 and lets an attacker run commands with no login), one in HPE Juniper networking gear (CVE-2026-103406), one in Vates Xen Orchestra (CVE-2026-133469, scored 9.8, lets an attacker skip the login and act as the boss account), and Danfoss refrigeration controllers. The remaining two are due 9 December 2026. Federal agencies must meet these dates by law; everyone else should treat them as the honest urgency marker.

What this means for you: if you run a Drupal website, patch today. If you run any of the other named products, this weekend is the deadline, not next month.

Source: Cybersecurity News, CISA adds 10 flaws to KEV, reporting CISA's 25 November 2026 additions

1. Critical vulnerabilities and patching

Microsoft fixes a crash its own November update caused on Windows Server 2025

Microsoft released an emergency repair, numbered KB5138318, after its November security update (KB5131077) made some Windows Server 2025 machines crash with a blue screen error, code 0x139, when a certain kind of internet address route (an IPv6 route, a direction for reaching other computers) expired on servers using a setting called Router Advertisement. The fix installs itself through Windows Update on enrolled servers and, unusually, needs no restart. This is a reliability fix, not a security hole, but a server that crashes on a timer is a server that stops serving.

Source: BleepingComputer, Microsoft emergency hotpatch, November 2026

Trailer brakes that any nearby stranger could squeeze: Elecbrakes Bluetooth flaws

Detailed research published this week covers three flaws in Elecbrakes trailer brake controllers (models EB2, VM1 and ELBC 2000), the boxes that apply a trailer's brakes. Two flaws score 9.6 out of 10: CVE-2026-96805, the brake controls accepted commands over Bluetooth, the short range wireless link phones use, from any device nearby with no pairing and no password; and CVE-2026-125273, commands could be recorded and replayed because they carried no freshness check. A third, CVE-2026-124281 (6.1), covers a weak software update path. In plain terms, a person within about 100 metres with a phone could squeeze or release someone else's trailer brakes. Four data bytes were enough. Firmware fixes exist for EB2 (version 3.0.4.4.3) and VM1 (1.3.4.2.1) and install through the app; the older ELBC 2000 has no fix yet, and its maker advises keeping your phone or remote connected while it is in use. CISA and the researchers report no known real world misuse, damage or injury.

Source: SecurityWeek, Elecbrakes braking controller vulnerabilities

2. Breaches and incidents

Backloggd game tracking site urges every user to change their password

Backloggd, a site where over a million people log the video games they play, disclosed on 25 November that an attacker used a bug to reach its internal admin tools. The attacker could see usernames, email addresses, password hashes and sign in IP addresses. A hash is a password scrambled one way into a fingerprint; it cannot simply be read back, but weak or common passwords can be guessed from it by trying millions of candidates. No payment, ID or financial data was taken; the site does not store it. The site was taken offline, the bug fixed, everyone logged out, and the attacker's changes are being undone. If you use Backloggd, change that password, and change it anywhere you reused the same one.

Source: Engadget, Backloggd urges users to change passwords after a breach

Still developing from yesterday: the 1Password breach

Password manager company 1Password disclosed on 25 November that an attacker who took over an employee's GitHub account pushed malicious code into its back end systems and stole customer names, emails and account details. The company states the vaults, where customers' actual passwords live, and their encryption keys were not accessed. No password reset is required; the practical risk is convincing fake 1Password emails, called phishing, so treat unexpected 1Password messages with suspicion.

Source: BleepingComputer report of 25 November 2026, carried in yesterday's SNI Daily Brief.

3. Threat actors and campaigns

No new named campaign broke in the last 24 hours beyond the SAP incident above, whose attacker is unknown and unattributed. Two standing warnings from this week remain live: a Black Friday phishing campaign that tricks people into typing a device sign in code into Microsoft's real login page, handing the attacker their Microsoft 365 account (only ever type a device code that you started yourself), and reporting that the China linked group Salt Typhoon is using an AI attack tool called ARTEX. Both are single thread reporting at this stage and are flagged as such.

4. AI and offensive security

Two threads, both flagged unverified. First, Der Spiegel's sources say the SAP attackers may have used AI agents; SAP has not confirmed any AI role. Second, the Elecbrakes researchers state openly that they used an AI coding assistant to map the brake controller's Bluetooth controls, a clean public example of AI speeding up honest vulnerability research. Italy's and Switzerland's national cyber agencies also warned this week about AI assisted attacks on critical infrastructure, meaning the power, water and transport systems everyone depends on; Switzerland says organisations in at least two such sectors were affected.

5. Policy, enforcement and industry

The United States Treasury's FinCEN bureau, which collects financial crime reports, took systems offline this week after a cyber incident and extended filing deadlines for affected institutions (reported by SecurityWeek, developing). CISA's fixing deadlines in the Top 3 item are the other hard dates in this window: today for the Drupal flaw, tomorrow for eight more.

2. Drupal sites: patch now. CVE-2026-132165 deadline is today, 27 November 2026; CVE-2026-136716 is fixed in Drupal 11.4.14, 11.3.23 and 10.6.23.

5. Elecbrakes EB2 and VM1 owners: update firmware in the app. ELBC 2000 owners: no fix yet; keep your phone or remote connected while towing.
