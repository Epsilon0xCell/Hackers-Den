Hackers-Den

The paper is regenerated daily at 03:00 UTC by GitHub Actions, sixteen feeds gathered into a Matrix styled newspaper and published through GitHub Pages.

Posting one, what arrives here

Sixteen feeds are gathered into one page. Named among the sixteen entries in config.yaml: Krebs on Security, The Hacker News, Schneier on Security, BleepingComputer, Dark Reading and the SANS Internet Storm Center podcast. Three of them are newsletters routed through kill-the-newsletter, plus Hacking Humans and Darknet Diaries among the podcast feeds.

Posting two, how the paper gets made

Java 17 runs rsspaper-1.2.4-standalone.jar and dist/ comes out plain. Then update_feed.sh lays green on black styling, digital rain, terminal style article headers and staggered article movement over it, with matrix-theme-backup/ holding the canonical CSS and JavaScript.

Posting three, carrying it away

A service worker and manifest make the paper installable as a PWA, with shell assets cached for offline reading.

Posting four, run it yourself

java -jar rsspaper-1.2.4-standalone.jar
./update_feed.sh

The second command alone does the whole job, because update_feed.sh runs the JAR as its first step. Perl is needed for two scoped edits in the theme script.

Posting five, credits and limits

RSSPAPER by its upstream makers, hosting by GitHub Pages. dist/ is regenerated and not to be edited by hand. site_methods.txt keeps the notes on how the feed list was chosen. The candid line stays on the board: no test files exist yet.
